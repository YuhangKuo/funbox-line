# Funbox 抽陀螺

整理 Funbox／來玩聚抽陀螺的指定商品、門市、抽選時間與 LINE 連結。

## 主要操作

### 新增追蹤商品

> **「新增追蹤商品 XXX」**

依 RULES.md 確認商品後加入追蹤清單，並同步核對 INDEX。

### 更新 INDEX

> **「更新 INDEX」**

按照 RULES.md 核對最新來源，只修正確定錯誤，再 commit。

## 核心規則

- 只追蹤 RULES.md 指定商品。
- 來源出現其他商品，不自動加入 INDEX。
- 若使用者明確要求新增商品，RULES.md 新增後必須同步處理 INDEX，不得只更新 RULES.md 而結束。
- RULES.md 是追蹤清單，不代表所有商品都必須出現在 INDEX 的商品選單。
- 更新 INDEX 時，只有最新來源在固定 5 地區有可確認資料的商品才顯示在 INDEX；目前沒有資料的商品保留在 RULES.md，但不顯示在 INDEX。
- 新增商品進 INDEX 前，必須先確認其在固定 5 地區是否有可確認的販售／抽選資料；有資料才加入，沒有資料則保留在 RULES.md、不加入 INDEX。
- 固定地區：台北市、新北市、桃園市、新竹市、新竹縣。
- 相同型號、不同商品名稱分開處理；但 RULES.md 已明確指定的名稱變體（例如 UX-19 子彈獅鷲H／子彈獅鷲）視為同一商品。
- CX-00 迪卡狂怒 FT3-60T 統一視為 CX-00 迪卡狂怒。
- 不確定的資料不猜、不改。
- 以最新來源為準，採最小必要修改。
