# Funbox 抽陀螺

整理 Funbox／來玩聚抽陀螺的指定商品、門市、抽選時間與 LINE 連結。

## 使用規則

詳細規則以 [`RULES.md`](RULES.md) 為準。

### 更新資料

> 按照 RULES.md 全面核對 Funbox；只處理 RULES.md 指定商品，有問題就修正並 commit。

### 只檢查

> 按照 RULES.md 核對目前資料，有問題先告訴我，不要修改、不要 commit。

### 只更新型號

> 按照 RULES.md 核對商品型號，只更新 RULES.md 與 INDEX 的型號資料，其他資料不要動。

## 核心規則

- 只追蹤 `RULES.md` 指定商品。
- 來源出現其他商品，不自動加入 INDEX。
- 固定地區：台北市、新北市、桃園市、新竹市、新竹縣。
- 相同型號、不同商品名稱分開處理。
- `CX-00 迪卡狂怒 FT3-60T` 統一視為 `CX-00 迪卡狂怒`。
- 不確定的資料不猜、不改。
- 以最新來源為準，採最小必要修改。
